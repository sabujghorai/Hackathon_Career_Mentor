# 🎓 Career Mentor AI

> An AI-powered All-in-One Student Success Platform designed to empower students with personalized career roadmaps, AI-generated study notes, skill opportunities, and smart campus assistance.

---

## 📌 Project Overview

Many students struggle to find reliable career guidance, academic resources, and skill development opportunities in one centralized location. **Career Mentor AI** bridges this gap by unifying student-centric AI services into a single, seamless web application[cite: 1].

### 🛠️ Key Features
* 🗺️ **Personalized AI Career Roadmaps**: Tailored learning paths based on student skills, interests, and goals[cite: 1].
* 📝 **AI Notes & Summaries Generator**: Instant summarization and key insights from lecture content[cite: 1].
* 🌉 **SkillBridge Recommendations**: Smart recommendations for internships, hackathons, online courses, and projects[cite: 1].
* 🏛️ **Smart Campus Assistant**: Real-time access to campus notices, event schedules, and instant Q&A via an AI chatbot[cite: 1].
